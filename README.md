# 🛡️ Website Controller (DG ZIYAR First-Layer Protection System)

Created by **Nader Habib** | **DG ZIYAR First Layer Protection System**

Website Controller is a high-performance central administration dashboard for managing client websites, subscription billing cycles, automatic `cron-job.org` daily keep-alive pings, and first-layer lock overlays.

---

## 🌟 Key Features

- **Admin Login Shield**: Protected admin access (`digizier`).
- **Client & 5 Platform Accounts Manager**: Track client details along with Vercel, Supabase, GitHub, Cloudflare, and Cron-Job.org emails.
- **Direct Supabase Integration**: Cloud database sync with automatic fallback protection.
- **Daily 12:00 AM Midnight Keep-Alive Cron**: Automatic daily ping keeping client Supabase projects 24/7 active without falling into sleep mode.
- **Advanced Antigravity Prompt Generator**: Multi-framework instant prompt generator supporting Next.js (`dangerouslySetInnerHTML`), React/Vite, HTML, PHP, and WordPress.
- **Delete Protection Shield**: Requires typing `DELETE` before removing client records.

---

## 🚀 Tech Stack

- **Frontend Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS + Lucide React Icons
- **Database**: Supabase PostgreSQL Cloud Database
- **Cron Service**: `cron-job.org` REST API integration
